# Changelog

## 1.5.0
- **Game Mode:** while a game runs, NEVIX lowers its own priority and freezes animations, glass effects and polling when it is not the focused window. Optional "minimize when a game starts".
- **Real GPU stats:** NVIDIA cards show usage, temperature and VRAM; other GPUs show usage only.

## 1.4.0
- Animated sky background: twinkling stars and shooting stars (can be turned off in Settings).

## 1.3.0
- Steam games are launched through Steam (`steam://rungameid/...`) like a desktop shortcut.
- **Quick Drop:** drag a shortcut (`.url` / `.lnk`) or `.exe` anywhere in the window to add it.
- Removed MY GAMES from the sidebar (the library lives on Home).

## 1.2.0
- Manual game icons (ICON button) and publisher metadata in the exe properties.

## 1.1.0
- Renamed to **NEVIX**. First-run PC scan for installed games, animated 5-second welcome screen with your name.
- Self-repair when a launch fails (finds moved games, tries the Windows shell, asks you to locate the exe).
- Game icons are extracted from the game's exe.
- Removed dark-mode / auto-save settings, notifications button and the avatar.

## 1.0.0
- First release (as NEXUS): library, ADD GAME, LAUNCH, favorites, search, statistics, system monitor, settings.
